## 一、年级单科平均分

### 1.1 数据模型

新表 `grade_subject_averages`（年级单科均分，人工录入——覆盖本系统没有其他班数据、无法自动计算的场景）：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | PK | |
| semester | String | 学期名 |
| exam_type | String | 考试类型 |
| exam_date | Date | 考试日期 |
| subject_id | FK subjects | 科目 |
| avg_score | Float | 年级平均分（原始分） |
| created_at / updated_at | timestamptz | |

唯一键 `(semester, exam_type, exam_date, subject_id)`，与"考试 = 类型+日期"的既有聚合口径一致。

**"同步所有记录"的实现方式（重要决策）**：录入后**不回写**每条 Score 行（避免冗余存储与一致性问题），所有展示处按唯一键联查即时带出——效果上等同于同步到该次考试该科目的全部成绩记录，且无同步延迟/漏同步风险。

### 1.2 一键录入入口（放在「成绩管理」页）

成绩管理页头部新增**「年级均分」按钮** → 弹窗：
- 上方三个条件：学期（下拉）+ 考试类型（可输可选）+ 考试日期（日期选择器）；
- 条件齐后下方表格自动列出**该班已配置成绩科目的全部科目**，每行一个均分输入框（可留空）；已有录入值自动回填（支持修改覆盖）；
- 一键保存：非空项批量 upsert。

放在成绩管理而非成绩分析的原因：这是**数据管理动作**（与录成绩同类），成绩分析是纯消费方。

### 1.3 成绩管理页展示逻辑（两点判断）

| 场景 | 处理 | 理由 |
|---|---|---|
| **未选科目** | **不显示年级平均卡** | 当前列表是跨科目混合，单一"年级平均"数字没有对应物，展示必误导；统计卡只反映当前列表真实统计 |
| **已选科目** | 显示「年级平均」第四张卡：定位**当前筛选范围内该科目最近一场考试**（若筛选了考试类型则在该类型内取最近日期），有录入值则显示，无则显示**「待录入」+ 快捷按钮**（直达录入弹窗并预填当前条件） | 与"该次考试该科目"的参照语义一致 |

### 1.4 成绩分析联动

- 考试报告「各科成绩指标」表新增**「年级均分(录入)」**列：有录入值显示原始分，无则显示 `-`；
- **科目均衡雷达图的"全校"系列优先采用录入的年级均分**（折算为得分率），无录入时回落到按库内数据计算的全校均分——图例注明数据来源，这解决了"系统里只有一个班时雷达图两条线重合"的问题。

### 1.5 后端接口（挂 `/api/scores`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/grade-averages?semester=&exam_type=&exam_date=` | 查询一场考试各科已录入均分 |
| POST | `/grade-averages` | 批量 upsert：`{semester, exam_type, exam_date, items:[{subject_id, avg_score}]}`，仅保存非空项 |
| DELETE | `/grade-averages/{id}` | 删除单条（展示回落为待录入） |

## 二、成绩日期去时间化 + 批量删除

### 2.1 exam_date 改为纯日期

- 模型 `Score.exam_date`：`DateTime(timezone=True)` → `Date`；Alembic 迁移用 `USING exam_date::date` 转换（库里现值均为 00:00:00，无损；**考试聚合键本就只取日期部分，迁移后所有既有考试 key 不变**）。
- 连带调整：成绩录入弹窗日期选择器 `datetime→date`、批量导入 value-format `YYYY-MM-DDTHH:mm:ss → YYYY-MM-DD`、后端日期解析、run.py 种子日期、响应序列化。

### 2.2 按条件一键删除历史成绩

- 接口（`/api/scores`）：
  - `GET /batch-count`：按条件实时预览命中条数（班级必选，学期/科目/考试类型/考试日期可选）；
  - `DELETE /batch-delete`：删除全部命中记录，写操作日志（记录条件与数量）。**班级为必选条件**，防止误删全库。
- UI：成绩管理页头部「批量删除」危险按钮 → 弹窗内条件级联选择 + **实时条数预览** + 输入 `DELETE` 二次确认。删除同时级联清理受影响的满分物化记录（场次满分行在无成绩时一并清除，避免悬空配置）。
