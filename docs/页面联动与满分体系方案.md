## 二、设计

### 2.1 页面联动（成绩管理 → 成绩分析）

- 成绩管理「成绩分析」按钮：`router.push({ path: '/analysis', query: { class_id, semester, exam_type, subject_id } })`（只带已选中的条件）。
- 成绩分析页 `onMounted` 读取 `route.query`：`class_id`/`semester` 校验存在后预选；`exam_type` 传给考试报告组件，用于预选**该类型最近一场考试**并直接出报告；`subject_id` 预选学生分析 Tab 的科目上下文（暂存，用于多人单科趋势卡片预选科目）。
- 学生下拉不联动（个人隐私语义上无对应）。

### 2.2 考试类型细化 + 班级排名移除

**成绩管理**：顶部新增「考试类型」下拉（可输入可选，常用五类），透传给列表查询与导出；联动跳转时一并携带。

**成绩分析-学生分析 Tab**：
- 「成绩趋势」：新增考试多选（el-select multiple，默认全选），折线图只画选中的考试；
- 「科目分析」：保持单选一场考试（考试多时 radio 按钮组改为下拉选择器）；
- 新增「单科多人趋势」卡片（承接班级排名页能力）：科目 + 多名学生 → 折线图，数据来自现有 `/api/analytics/subject-trend`。

**成绩分析-考试报告 Tab**：
- 各科指标表新增「满分」「得分率」列和「单科名次」操作（弹窗展示该科该场考试名次表，承接班级排名页能力）。

**移除班级排名**：删除 `views/Rankings.vue`、路由、`PAGE_REGISTRY` 条目、Layout 菜单项。数据库 `page_access_configs` 中 `/rankings` 的历史配置行成为无害孤儿（页面访问管理按 PAGE_REGISTRY 渲染，不会显示）。仪表盘的班级/学生排名接口与卡片不受影响。

### 2.3 科目满分体系（三层模型）

```
解析顺序（高→低）：
3. 场次实例：ExamFullScore(class_id, subject_id, exam_type, exam_date)   ← 导入时物化，事后可改
2. 考试类型默认：ExamTypeFullScore(subject_id, exam_type)               ← 科目管理里配置，如「数学×模拟考试=150」
1. 科目默认：Subject.full_score（默认 100）                              ← 科目管理里配置
兜底：100
```

**数据模型**（Alembic 迁移）：
- `subjects.full_score FLOAT NOT NULL DEFAULT 100`
- 新表 `exam_type_full_scores(id, subject_id FK, exam_type, full_score, created_at/updated_at, UNIQUE(subject_id, exam_type))`
- 新表 `exam_full_scores(id, class_id FK, subject_id FK, exam_type, exam_date DATE, full_score, created_at/updated_at, UNIQUE(class_id, subject_id, exam_type, exam_date))`

**后端行为**：
- `resolve_full_score(db, subject_id, exam_type, exam_date, class_id)` 统一解析函数（放 `app/scoring.py` 新模块，含缓存字典避免重复查询）。
- **批量导入**：对涉及的每对（科目, 考试类型+日期）**物化** ExamFullScore（按解析结果），成绩校验改为 `0 ≤ score ≤ 满分`（错误信息带满分值）。
- **单条录入/修改**：按解析结果校验上限（不物化）。
- **成绩列表**：`ScoreResponse` 增加 `full_score`（该条成绩的生效满分），前端成绩颜色标签按 得分率 分档。
- **分析折算**（全部改口径）：
  - 考试报告：subjects 表加满分/得分率；三率按 得分率≥90%/≥60%/<40%；summary 与 10 分段按个人折算平均分；名次按**折算总分**排名（展示原始总分+折算均分）；临界生按折算均分；均衡雷达用折算均分（班级 vs 全校）。
  - 学生分析：rank_trend 按折算总分排名；薄弱科目按折算分差距（阈值仍 5 分）；科目对比表加满分列。
  - 班级分析/对比接口：分布与均分按折算。
  - 仪表盘 avg_score 改为折算平均（Python 端计算）；单科排名（同科同场）原始分=折算排名，不动。

**前端 UI**：
- **科目管理**：科目表加「满分」列（默认 100，可编辑）；新增「考试类型满分」按钮 → 弹窗（已配置列表 + 新增行：科目/考试类型(可输可选)/满分，可删除）。
- **成绩分析-考试报告**：考试下拉旁「本场满分」按钮 → 弹窗列出本场各科目的生效满分（显示来源：场次/类型默认/科目默认），修改后保存为场次实例级；报告各区域展示满分信息。
- **成绩录入弹窗**：分数输入上限从固定 100 改为按所选学生班级+科目+考试类型动态解析的满分。

**新端点**：
- `GET/POST/DELETE /api/subjects/exam-type-full-scores`（列表/新增(幂等覆盖)/删除）
- `PUT /api/analytics/exam-full-score`（upsert 场次实例满分）、`DELETE /api/analytics/exam-full-score`（清除回落到上层）
- `GET /api/analytics/exam-report` 响应扩展（subjects[].full_score、rankings 改折算口径等）

**明确不做**：家长端成绩展示保持原始分（家长看原始分更直观）；Excel 导入模板不做"满分行"（满分由配置继承，导入后可改）。
